# nubit-oauth
Personal tooling account for a set of private Google Apps Script web apps (a geography quiz, a running planner, a travel-day tracker and a board game).

The apps are personal projects, used by their author and by people he shares a link with. This repository exists only to provide the home page and privacy policy URLs that Google Cloud requires in order to move an OAuth consent screen out of testing mode.

There is no product, no sign-up and nothing to install here.

See PRIVACY.md.
